# 📈 探索性分析 Notebook

打开 `notebooks/exploration.ipynb` 即可（需要 jupyter）。

或者在命令行里跑：

```bash
.venv/bin/jupyter lab notebooks/
```

主要内容：

1. **数据探索** — 价格 / 收益 / 因子载荷 / 行业相关性
2. **图结构诊断** — 度分布、聚类系数、连通分量、社区结构
3. **模型对比** — 各模型 AUC、长短收益、按行业/regime 切片
4. **消融可视化** — 边 drop 曲线 + 特征重要性

你可以直接编辑这个 notebook 做自己想要的探索。
